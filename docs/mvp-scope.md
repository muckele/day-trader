# Day Trader MVP v1 scope

Owner-only React/Express/Mongoose application, bound by operator configuration to one Alpaca paper account. Public signup, live execution, shorting, margin, options, crypto, leveraged/inverse ETFs and overnight automation are outside this release. Local simulation must remain explicitly separate. No profitability claims.

The full implementation contract is preserved in `mvp-request.txt`. No external trading, production deployment, paid infrastructure, persistent external automation, account reset or destructive history cleanup is authorized by this work.
